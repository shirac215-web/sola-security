# Sola Security Platform

An advanced full-stack application integrating AI models, Meta WhatsApp API, and Google Calendar integration to streamline communication and scheduling workflows.

## Core Features & Integrations
- **AI Integration:** Utilizes AI models for smart text processing and automation.
- **WhatsApp Bot Service:** Connected to Meta's WhatsApp API for automated messaging and real-time communication.
- **Google Calendar Integration:** Manages scheduling and meeting synchronization using Google Calendar.
- **Administrative Dashboard:** Client interface for managing system operations and data.

## Tech Stack
- **Backend:** Node.js, Express
- **APIs & AI:** Meta WhatsApp API, AI Models, Google Calendar API
- **Deployment & Infrastructure:** Netlify, Render
